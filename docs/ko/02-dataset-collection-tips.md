# 2. 데이터셋 모을 때 팁 (블랙박스 도로 결함)

첫 모델은 val 점수는 괜찮았는데 내 블랙박스 영상에서는 포트홀·크랙을 거의 못 잡았다.
데이터가 카메라와 달랐기 때문이다. 지금은 아래 규칙을 지킨다.

## 사진 고르기

1. **내 카메라와 같은 시점의 사진만 쓴다.**
   블랙박스라면 하늘·차선·앞차가 보이는 앞유리 시점, 결함은 멀리서 작게 보인다.
2. **빼는 사진:** 사람이 서서 바닥을 내려다보고 찍은 사진, 결함만 확대한 사진,
   드론·위성 사진, 스트리트뷰.
3. **장면 종류도 본다.** 시골 비포장길이나 외국 고속도로만 있는 데이터는 도심 도로에서 잘 안 통했다.
4. **다운로드 전에 데이터셋 페이지의 샘플 사진을 넘겨보고**, 클래스별 개수(Roboflow *Health Check*)를 확인한다.

## 특정 클래스 찾기 (RDD 코드)

도로 파손 데이터셋 대부분이 RDD(Road Damage Detection) 챌린지 코드를 쓴다.
이름보다 코드로 검색하는 게 빠르다.

| RDD 코드 | 뜻 | 내 클래스 |
|---|---|---|
| D00 | 세로 크랙 | 1 Crack |
| D10 | 가로 크랙 | 1 Crack |
| D20 | 거북등 크랙 | 사용 안 함 (라벨 삭제) |
| D40 | 포트홀 | 0 Pothole |
| D43 | 횡단보도 흐림 | — |
| D44 | 차선 흐림 | 6 Poor_lane |

검색어 예시: `dashcam pothole`, `dash cam road damage`, `RDD2022`, `D44`, `white line blur`.

같은 코드라도 데이터셋마다 이름이 다르다 (`D40rotation`, `pothole`, `Pothole-1` 등).
받은 뒤 `data.yaml`의 `names` 목록을 보고 번호 변환표를 직접 만든다.

## 다운로드 설정 (Roboflow)

5. **형식:** YOLOv11 (YOLOv8도 라벨 형식은 같음).
6. **증강(Augmentation)은 끈다.** Roboflow의 "×3" 복사본은 새 데이터가 아니고,
   YOLO가 학습할 때 알아서 증강한다 (좌우 반전, 색상, 모자이크, 크기 등).
7. **뒤집어지거나 회전된 사진은 뺀다.** 상하 반전, 90°·180° 회전은 블랙박스에서 절대 나오지 않는 장면이라
   쓸모없는 것만 배우게 된다.
8. **`Resize: Stretch`는 피한다.** 16:9 사진을 640×640으로 늘리면 모든 물체가 찌그러진다.
   원본 크기로 받거나 `Fit (black edges)`를 쓴다.
9. 증강된 버전밖에 없으면 **원본당 1장만** 남긴다.
   Roboflow 파일명은 `name_jpg.rf.<hash>.jpg` 형태이고, `.rf.` 앞부분이 같으면 같은 원본이다.

## 받은 뒤 라벨 확인

10. **사진 20장 정도 직접 열어서 박스를 본다.**
11. **보이는 결함에는 전부 박스가 있어야 한다.** 박스 없는 포트홀은 "포트홀 아님"으로 학습된다.
12. **사진마다 내 클래스를 전부 라벨링한다.** 그 데이터셋의 목적 클래스만이 아니라
    (예: 차선도색불량 사진 속 크랙).
13. **박스가 듬성듬성하거나 너무 작은 데이터는 버린다.** 사진마다 크랙 몇 개만 라벨된 데이터로는
    크랙을 거의 못 잡았다.
14. 안 쓰는 클래스는 지운다 (거북등 크랙 박스를 지우고, 거북등만 있던 사진은 뺐다).
15. 라벨 한 줄 형식: `클래스 x중심 y중심 너비 높이`, 좌표는 모두 0~1.

## train / val 나누기

16. **사진 단위가 아니라 그룹 단위로 나눈다.** 같은 원본의 증강본, 같은 영상의 프레임은
    한쪽에만 들어가야 한다. 섞이면 val이 train과 거의 같은 사진으로 채워져 점수가 부풀려진다.
17. 영상에서 프레임을 뽑을 때는 **1초에 1장 이하**로 뽑는다.
18. **박스 없는 배경 사진을 train의 약 10%** 넣는다: 정상 시설물(멀쩡한 중앙분리대·볼라드),
    결함과 헷갈리는 것(맨홀, 횡단보도, 차선, 그림자, 얼룩).
19. **내 영상 하나는 학습에서 완전히 빼고** 시험용으로만 쓴다.

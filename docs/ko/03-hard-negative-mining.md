# 3. 오탐 사진으로 보강하기 (hard-negative mining)

공개 데이터셋에는 *내* 카메라가 결함으로 착각하는 물체가 거의 없다.
가장 빨리 찾는 방법은 내 영상으로 검출해 보고 결과를 분류하는 것이다.

## 반복 순서

1. **검출**: 내 영상으로 검출하고 검출된 것을 전부 저장한다.
   ```bash
   python scripts/custom_detect.py --model best.pt --source video.mp4 \
       --resolution 1280x720 --no-gnss --thresh 0.5 --sample-sec 1.5
   ```
   검출될 때마다 박스 표시 사진(`result/`), 원본(`result_raw/`), YOLO 형식 박스(`result_label/`)가 저장된다.
2. **직접 분류**: `result/`의 사진을 `맞음/`, `틀림/` 폴더로 옮긴다.
3. **클래스별 정확도**: 맞음 ÷ 저장된 장수.
4. **데이터셋에 추가** (`train`에만):
   - 맞음 → 원본(`result_raw/`) + 검출 박스(`result_label/`)를 새 라벨 사진으로
   - 틀림 → 원본 + **빈 라벨 파일**을 배경 사진으로
   - 시험용 영상에서 나온 사진은 전부 뺀다
5. **데이터셋을 다시 만들고 재학습**한 뒤, 시험용 영상으로 다시 확인한다.

## 결과

| | v3 | v5 (+ 배경 사진 127장 ×3) |
|---|---|---|
| 포트홀 검출 | 138 (확인한 121개 모두 맨홀) | **0** |
| 시험용 영상 | 5 (모두 틀림) | **0** |

학습에 한 번도 쓰지 않은 시험용 영상에서도 오탐이 사라졌다.
그 프레임들을 외운 게 아니라 "맨홀 ≠ 포트홀"을 배운 것이다.

## 주의할 점

- **시험용 영상 사진은 절대 넣지 않는다.** 넣으면 시험 점수가 의미 없어진다.
  저장 파일명에 영상 이름을 넣어서 걸러낼 수 있게 한다.
- **맞음 사진은 박스가 전부 맞아야 한다.** 박스 하나가 틀렸거나 결함 하나가 빠졌으면
  라벨을 고친 뒤 넣는다. 아니면 그 실수까지 학습된다.
- **검출 0개가 무조건 좋은 건 아니다.** 시험용 영상에 진짜 포트홀이 없으면
  모델이 진짜 포트홀을 아직 잡을 수 있는지 알 수 없다. 확실한 정답 사진 몇 장으로 같이 확인한다.
- 채굴한 사진은 공개 데이터보다 훨씬 적으니 조금 반복해서 넣는다 (나는 ×3).
